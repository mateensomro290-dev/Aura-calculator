# Aura Calculator ✨

**Aura Calculator** is an exquisitely designed, modern scientific web calculator built with an obsidian black body, tactile gray keys, ambient aura illumination, and dedicated **Day Mode** and **Night Mode**.

---

## 🌟 Key Features

### 1. Aesthetic Design
- **Day Mode (Default)**: Crisp, luminous white page background paired with a deep, satin-finished black calculator chassis and multi-tone gray keys.
- **Night Mode**: Deep midnight cosmic background with glowing backlight keys and an intense ambient breathing neon aura halo.
- **Gray-Colored Tactile Keypad**:
  - **Numbers (0-9, 00, .)**: Slate gray keys with crisp high-legibility typography.
  - **Operators (+, −, ×, ÷, =)**: Cool steel/graphite gray keys with aura hover highlights.
  - **Utility Functions (AC, ⌫, %, ±, ())**: Charcoal gray keys with tactile press states.
- **Customizable Aura Colors**: Switch live between **Cyan**, **Violet**, **Emerald**, **Amber**, and **Rose** aura glow accents.

### 2. Powerful Mathematical Capabilities
- Standard arithmetic: Addition, Subtraction, Multiplication, Division, Percentages, and Inversion.
- Multi-step expressions with parentheses `(` and `)`.
- **Scientific Mode (`fx`)**:
  - Trigonometry: `sin`, `cos`, `tan` with `DEG` / `RAD` angle toggle.
  - Logarithms: `ln` (natural log) and `log` (base-10).
  - Powers & Roots: Square root `√`, square `x²`, exponentiation `xʸ`.
  - Constants: `π` (Pi) and `e` (Euler's number).
  - Reciprocal `1/x`.
- Safe math evaluation with divide-by-zero protection.
- Large number formatting with dynamic comma separators and auto-scaling font size.

### 3. Tactile Feedback & Extras
- **Haptic Sound Feedback**: Built-in, zero-dependency Web Audio API click synthesis (can be toggled on/off).
- **Calculation History**: Popover history drawer to review, recall, or clear past calculations.
- **One-Click Copy**: Copy any result to your clipboard with animated feedback.
- **Keyboard Support**: Complete physical keyboard integration for desktop use.
- **Responsive Layout**: Pixel-perfect on both desktop displays and mobile phones.

---

## ⌨️ Physical Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `0` - `9` | Input Digits |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Arithmetic Operators |
| `Enter` or `=` | Calculate Result |
| `Backspace` | Delete last digit |
| `Escape` | Clear All (`AC`) |
| `%` | Percentage |
| `(` and `)` | Parentheses |

## 🚀 How to Run

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari):

```bash
# Windows PowerShell
Start-Process "index.html"
```
